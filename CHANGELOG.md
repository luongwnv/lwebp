# Changelog

All notable changes to the **lwebp** extension will be documented in this file.

## [0.1.0] - 2026-03-12

### Added
- Convert images to **WebP**, **JPEG**, or **PNG** format
- Sidebar panel in Activity Bar with full conversion UI
- Image preview with dimensions and file size display
- Quality slider with real-time estimated output size
- Output format selector (WebP, JPEG, PNG)
- Visual crop tool with mouse drawing and manual coordinate input
- EXIF data viewer (camera, lens, exposure, ISO, GPS, etc.)
- Batch conversion with progress tracking
- Custom image editor ("Reopen Editor With..." support)
- Context menu integration (Explorer & editor tabs)
- Right-click folder to batch convert all images
- Quality selection dialog for on-the-fly quality choice
- Configurable settings: quality, delete original, output directory
- Smart `_converted` suffix when input and output formats match
- Support for animated GIF conversion
- HEIC/HEIF input format support
